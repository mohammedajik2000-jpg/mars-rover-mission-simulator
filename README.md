# 🚀 ARES-IV | Interactive 3D Mars Rover Mission Simulator

An interactive 3D space mission simulation that takes users through the engineering, launch, interplanetary travel, landing, and exploration of a Mars rover.

## 🌌 Project Overview

ARES-IV is an interactive Mars rover engineering and space mission simulator designed to demonstrate the major stages of a robotic Mars exploration mission through an immersive 3D experience.

Users can experience rover assembly, system diagnostics, rocket launch, deep-space travel, Mars landing, scientific exploration, and mission data transmission.

## 🎯 Mission Phases

1. **Rover Assembly** – Assemble the rover and its essential components.
2. **System Activation** – Activate components and perform system diagnostics.
3. **Earth Launch** – Experience the rocket launch sequence.
4. **Deep Space Journey** – Travel from Earth towards Mars.
5. **Mars Landing** – Experience atmospheric entry and rover deployment.
6. **Mars Exploration** – Navigate the rover and perform scientific activities.
7. **Data Transmission** – Transmit mission data and view the mission report.

## ✨ Key Features

- Interactive 3D rover simulation.
- Multi-stage space mission experience.
- Rover assembly and system diagnostics.
- Rocket launch and spacecraft journey.
- Mars landing simulation.
- Interactive rover navigation.
- Scientific exploration activities.
- Mission data transmission dashboard.
- Phase-specific sound effects.
